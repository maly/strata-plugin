# prepare-doc

Spusť skill `prepare-doc` ze složky `skills/prepare-doc/` v tomto pluginu.

Skill analyzuje konverzaci a navrhne doplnění slovníků (`tools.yaml`,
`projects.yaml`) — nové nástroje, projekty nebo pojmy, které se v session
objevily, ale v slovnících ještě nejsou.

Výstup: soubor `.claude/dictionary-suggestions.yaml` s návrhy ke schválení.
